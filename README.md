# Universal Converter – Java Desktop Application

Desktop application that converts units and currencies. University team project (team of 4).

## Features
- Unit conversions: mass, volume, distance and area (e.g. kg, L, cm³) [adjust to what your app really does]
- Currency conversion using live exchange rates from the Frankfurter API (free, no API key required)

## Technologies
Java, JavaFX, exchange rate API
